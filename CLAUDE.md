# Novel Project — Working Protocol

This is a fiction project. The document system is the sole source of truth; chat history is disposable.

## Files
- 00 = SEALED author canon (Truths of the story that may NOT yet be revealed on the page. Never contradict; reveal slowly)
- 01–04, 06 = bibles (premise, world, characters, outline, style)
- 05 = continuity log (THE WORKHORSE — protocol, established facts, seed ledgers, NEXT TARGET, word-count baselines)
- Book_One_-_Chapter_XX = manuscript

## Session protocol (full rules live in 05 §Working Protocol — read them, they win over this file)
1. VERIFY: wc -w every chapter + 00 against the baselines in 05. Any mismatch = stale file → STOP and report before reading further.
2. COLD READ all bibles + all chapters. Flag anything that itches BEFORE any work. (review this rule when context becomes too big)
3. Confirm target via the NEXT TARGET block in 05. Never improvise a target, only if requested.
4. New chapters: mandatory design argument first (as specified in NEXT TARGET) → propose chapter shape → WAIT for approval → draft.
5. Revisions: propose per-chapter cut/addition tables with projected counts; flat-or-leaner rule per chapter; failed passes get redone.
6. Every decision commits to a file before session close. Single handoff at close; update baselines in 05.
7. Ceiling: two chapters of new prose per session; three only if structurally simple.
